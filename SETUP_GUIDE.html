PTV Discovery Coach — Setup Guide

This guide walks you through getting the live app running so you can test it. No programming experience needed. Follow each step in order.

Total time: approximately 30-45 minutes for first-time setup. After that, starting the app takes about 30 seconds.

Part 1 — Install Node.js 5 min

Node.js is the engine that runs the app. You only need to install it once.

1 Open your web browser and go to:
https://nodejs.org
2 Click the big green button that says "LTS" (Long Term Support). This downloads a file called something like node-v22.x.x-x64.msi.
3 Find the downloaded file (usually in your Downloads folder) and double-click it to run the installer.
4 Click Next → Next → Next → Install → Finish. Accept all the defaults. You don't need to change anything.
5 Verify it worked: Open Command Prompt (search "cmd" in the Start Menu), type this, and press Enter:
node --version
You should see something like v22.x.x. If you see an error, restart your computer and try again.
Node.js is installed. You won't need to do this step again.

Part 2 — Install Git 5 min

Git is the tool that uploads your code to GitHub and keeps it in sync.

1 Go to: https://git-scm.com/download/win
2 The download should start automatically. If not, click "Click here to download manually."
3 Run the downloaded installer. Click Next through every screen — the defaults are fine. Click Install, then Finish.
4 Verify it worked: Open a NEW Command Prompt window (close the old one first), type this, and press Enter:
git --version
You should see something like git version 2.x.x.
Git is installed. You won't need to do this step again.

Part 3 — Create a GitHub Access Token 3 min

This is like a password that lets your computer talk to GitHub securely.

1 Go to: https://github.com/settings/tokens
(Log in to GitHub if prompted)
2 Click "Generate new token (classic)"
3 Give it a name like discovery-coach
4 Under "Select scopes", check the box next to "repo" (this gives it permission to upload code)
5 Scroll down and click "Generate token"
6 IMPORTANT: Copy the token that appears (it starts with ghp_). Save it somewhere safe like a password manager or a sticky note on your desk. You will need it in the next step.
Never share your token in chat, email, or with anyone. Treat it like a password. If you accidentally share it, go back to the tokens page and delete it immediately, then create a new one.

Part 4 — Upload the Code to GitHub 5 min

This uploads all the app code from your computer to your GitHub repository.

1 Open Command Prompt (search "cmd" in Start Menu)
2 Navigate to the project folder by typing this and pressing Enter:
cd "C:\Users\joseph.phillips\OneDrive - PTV Logistics GmbH\Desktop\excel-to-json-ap\ptv-discovery-coach"
3 Run these commands one at a time, pressing Enter after each one:
git init
git add .
git commit -m "Initial commit"
git branch -M main
git remote add origin https://github.com/mrjfphillips-tech/discovery-coach.git
git push -u origin main
4 When it asks for your username, type your GitHub username: mrjfphillips-tech
When it asks for your password, paste the token you saved in Part 3 (the one starting with ghp_). Note: you won't see the characters as you paste — that's normal. Just paste and press Enter.
If you get an error saying "remote origin already exists", run this first, then try the push again:
git remote remove origin
git remote add origin https://github.com/mrjfphillips-tech/discovery-coach.git
git push -u origin main
Your code is now on GitHub. You can verify by going to https://github.com/mrjfphillips-tech/discovery-coach — you should see all the files.

Part 5 — Install the App Dependencies 5 min

This downloads all the libraries the app needs to run. You only do this once (or when the code changes significantly).

1 In the same Command Prompt window (still in the ptv-discovery-coach folder), run:
npm install
This will take 2-3 minutes. You'll see a lot of text scrolling by — that's normal. Wait until you see the cursor blinking again.
If you see warnings (yellow text), that's OK. Only red "ERROR" messages are a problem. If you see errors, try running npm install again.
Dependencies are installed. You're ready to run the app.

Part 6 — Run the App Locally 2 min

This starts the app on your computer so you can test it in your browser.

1 In the same Command Prompt window, run:
npm run dev:frontend
2 Wait about 10 seconds. You should see a message like:
VITE v5.x.x ready in xxx ms ➜ Local: http://localhost:3000/
3 Open your web browser and go to:
http://localhost:3000
The app is running. You should see the PTV Discovery Coach interface in your browser.
To stop the app, go back to the Command Prompt window and press Ctrl+C. To start it again later, just open Command Prompt, navigate to the folder, and run npm run dev:frontend again.

Part 7 — View the App in StackBlitz (No Install Alternative) 1 min

If you want to view the app without installing anything on your computer, you can use StackBlitz — a browser-based development environment.

1 After completing Part 4 (uploading to GitHub), open this URL in your browser:
https://stackblitz.com/github/mrjfphillips-tech/discovery-coach
2 StackBlitz will automatically detect the project, install dependencies, and start the app — all in your browser. This takes about 1-2 minutes the first time.
StackBlitz runs entirely in your browser. No software is installed on your computer. It's a great way to share the app with colleagues for feedback — just send them the StackBlitz link.

Troubleshooting

"npm is not recognized"

Node.js isn't installed or the Command Prompt was opened before installation. Close Command Prompt, restart your computer, and try again.

"git is not recognized"

Git isn't installed or the Command Prompt was opened before installation. Close Command Prompt, restart your computer, and try again.

"remote origin already exists"

Run git remote remove origin first, then re-add it with the git remote add origin command.

"Authentication failed"

Your GitHub token may have expired or been revoked. Go to github.com/settings/tokens, generate a new one, and try the push again.

"Port 3000 is already in use"

Another app is using port 3000. Either close that app, or the dev server will automatically try port 3001. Check the terminal output for the actual URL.

The app looks different from the demo

The demo.html is a static mockup. The real app (running via npm) uses the actual React components and may look slightly different. Both represent the same features.
