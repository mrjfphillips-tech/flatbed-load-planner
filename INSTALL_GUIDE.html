1. Prerequisites

You need these installed on your machine before starting:

ToolVersionHow to Check
Node.js18 or highernode --version
npm9 or highernpm --version
GitAny recentgit --version
Don't have Node.js? Download it from nodejs.org (LTS version recommended). npm comes bundled with Node.js.

2. Install Dependencies

1 Open a terminal

Open Command Prompt, PowerShell, or your preferred terminal.

2 Navigate to the project folder 
cd ptv-discovery-coach
3 Install all packages 
npm install

This installs dependencies for all packages (shared, frontend, backend, electron). Takes 2-3 minutes.

You should see added XXX packages with no errors. Warnings about deprecated packages are normal and safe to ignore.

3. Configure Environment Variables

4 Create the backend .env file

Copy the example file and fill in your values:

cd packages/backend
copy .env.example .env

Then open packages/backend/.env in a text editor and fill in:

# Database (SQLite for local dev, PostgreSQL for production)
DATABASE_URL="file:./dev.db"

# Auth0 (get these from your Auth0 dashboard)
AUTH0_AUDIENCE=https://ptv-discovery-coach
AUTH0_ISSUER_BASE_URL=https://YOUR-TENANT.auth0.com

# OpenAI (for AI question suggestions and summaries)
OPENAI_API_KEY=sk-your-openai-key-here

# Leexi Integration (optional - for call import/export)
LEEXI_API_KEY_ID=your-leexi-key-id
LEEXI_API_KEY_SECRET=your-leexi-secret

# Frontend URL (for CORS)
FRONTEND_URL=http://localhost:3000
Important: Never commit the .env file to Git. It contains secrets. The file is already in .gitignore.
VariableWhere to Get ItRequired?
DATABASE_URLUse the SQLite default for local devYes
AUTH0_AUDIENCEAuth0 Dashboard → APIsYes
AUTH0_ISSUER_BASE_URLAuth0 Dashboard → SettingsYes
OPENAI_API_KEYplatform.openai.comYes (for AI features)
LEEXI_API_KEY_IDLeexi → Settings → API KeysOptional
LEEXI_API_KEY_SECRETLeexi → Settings → API KeysOptional

4. Set Up the Database

5 Generate the Prisma client 
cd packages/backend
npx prisma generate

This creates the database client from the schema. You should see: Generated Prisma Client

6 Create the database tables 
npx prisma db push

This creates all the tables in your database. For local dev with SQLite, it creates a dev.db file.

7 (Optional) View the database 
npx prisma studio

Opens a web UI at http://localhost:5555 where you can browse and edit data.

5. Build the App

8 Build all packages

From the project root (ptv-discovery-coach/):

cd ../..
npm run build

This builds shared → backend → frontend → electron in order.

If the build succeeds with no errors, you're ready to run the app.

6. Run the App

Option A: Development Mode (recommended for testing)

Open two terminal windows:

Terminal 1 - Backend 
npm run dev:backend

Starts the API server at http://localhost:4000

Terminal 2 - Frontend 
npm run dev:frontend

Starts the web app at http://localhost:3000

Option B: Desktop App (Electron)

Build and run the desktop app 
npm run dev:electron

Opens the app as a native Windows application.

7. Leexi Integration Setup

Leexi integration is optional. Skip this section if you don't use Leexi for call recording.
1 Get your API keys

Log into app.leexi.ai → Settings → Company Settings → API Keys → Click "Add"

You'll get a Key ID and a Key Secret. Copy both.

2 Add keys to .env

Open packages/backend/.env and set:

LEEXI_API_KEY_ID=your-key-id-here
LEEXI_API_KEY_SECRET=your-secret-here
3 (Optional) Set up webhooks for automatic import

In Leexi: Settings → Webhooks → Add

  • Name: PTV Discovery Coach
  • URL: https://your-server.com/api/leexi/webhook

Leexi will send a test event. Your server must respond with a 200 status to activate the webhook.

What you can do with Leexi:

  • Pull: Import call transcripts from Leexi for MEDDIC analysis
  • Push: Send session recordings to Leexi for AI transcription
  • Webhook: Automatically import calls when Leexi finishes processing

8. Load the Question Bank

1 Open the Question Upload Template

Find the file: data/Question_Upload_Template.xlsx

It has 3 tabs: Instructions, Questions (with examples), and Valid Values reference.

2 Add your questions

Fill in the QUESTIONS tab. Each row needs:

  • question_text - The question to ask
  • meddic_element - Which MEDDIC area it targets (use dropdown)
  • buyer_persona - Who it's for (use dropdown)
  • coaching_note - Why ask this & what to listen for (optional but recommended)
  • industry_segment - Industry filter, or leave blank for universal (use dropdown)
3 Save as CSV and upload

File → Save As → CSV UTF-8 (.csv)

In the app: Admin → Question Bank → Bulk CSV Upload → Choose your file

A starter question bank with 200+ questions is included at data/starter-question-bank.csv. You can upload it directly.

9. Troubleshooting

ProblemSolution
npm install fails with permission errorsRun as Administrator, or check that Node.js is installed for your user account
EPERM: operation not permitted, lstatNode.js was installed under a different user. Reinstall Node.js from nodejs.org for your user
prisma generate failsMake sure you're in the packages/backend directory and npm install completed first
Backend won't start - missing .envCopy .env.example to .env and fill in the values
Leexi returns 401 UnauthorizedDouble-check your API Key ID and Secret. Make sure the key is active in Leexi settings
Leexi returns 403 / error 1010Cloudflare is blocking the request. Make sure you're using the correct base URL: https://public-api.leexi.ai/v1
Frontend shows blank pageCheck that the backend is running on port 4000 and CORS is configured in .env
Questions not showing during sessionUpload the question bank CSV via Admin → Bulk Upload
